# Doe-Flatscreen-mod
A mod for dungeons of eternity that makes it flatscreen

INSTALLATION

1. Use the latest version of melonloader to patch the game
2. run the game
3. Copy the DLL and put it in the mods folder
4. YOUR READY TO GO!

CONTROLS
WASD | movement
E | force grab
Middle click | let go
I | inventory
M | menu
Left/right click | attack
1,2,3 | select weapon
